### Git 및 GitHub 사용 실습

1. 이 저장소를 팀별로 팀장이 ```fork``` 하도록합니다.
2. 각 팀원들은 ```fork```된 저장소를 각자 PC에서 ```clone```합니다.
3. 팀원별로 나눠서 hasChild(), height(), dfs(), bfs() 메소드 등을 구현합니다.
4. 각자 맡은 부분을 새로 ```branch```를 만든 뒤 구현해서 ```commit```합니다.
5. 여기서는 두 가지 선택지가 있습니다. 새 브랜치를 ```main``` 브랜치로 ```merge```하거나, 새 브랜치에서 원격의 ```main```에 **Pull Request (PR)**를 하는 것입니다.
6. 우선 PR을 작성해 등록하고 GitHub에 해당 PR이 나타나는 것을 확인합니다.
7. 모든 팀원의 PR이 ```main```에 통합되고 나면, 각자 로컬 저장소의 ```main``` 브랜치에서 ```pull```하여 내용을 가져옵니다.
8. 이제 아까 작성했던 새 브랜치로 ```switch```하고, ```main```의 변경내용들을 여기에 ```merge```하도록 합니다.
9. 이후 추가 수정이 필요하면 이 브랜치에서 최신 변경이 반영된 상태에서 작업을 이어갈 수 있습니다.
